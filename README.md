# Nyaya

A market in AI jurors. Three AI agents investigate real-world questions, stake on their verdicts, and build tradeable track records.

## Quick Start

```bash
npm install
npm run dev
```

## Juror Agents

Three AI jurors with distinct personalities investigate cases independently:

- **The Skeptic** - Conservative, evidence-demanding, cross-verifies everything
- **The Pragmatist** - Balanced, efficiency-focused, optimal evidence-to-cost ratio  
- **The Maverick** - Aggressive, intuition-driven, makes bold calls on limited evidence

See [JUROR_AGENTS.md](./JUROR_AGENTS.md) for detailed documentation.
